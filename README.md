# The Ms Gugappriyaa Awards

A private cinematic award ceremony for Ms Gugappriyaa.

## Run

```bash
npm install
npm run dev
```

Open the local URL, then press **Begin Ceremony**. Audio unlocks on that tap.

## Replace assets

Edit only `src/data/awards.js` for copy, quotes, and paths.

- Photos: `public/images/gugaa/`
- Music: `public/audio/awards/`

Missing photos become an elegant placeholder. Missing music falls back to an original synth bed. The previous track always fades out before the next one starts.
