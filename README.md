# The Ms Gugappriyaa Awards

A private cinematic award ceremony for Ms Gugappriyaa.

## Run

```bash
npm install
npm run dev
```

Open the local URL. The theme starts on the welcome page. Press **Begin Ceremony** to enter the awards.

## Replace assets

Edit only `src/data/awards.js` for copy, quotes, and paths.

- Photos: `public/images/gugaa/`
- Music: `public/audio/awards/`
